Book API - Gerenciador de Livros (Etapa 1)

Projeto desenvolvido como parte da avaliação do 3º Bimestre, focado no desenvolvimento de uma API RESTful para gerenciamento de livros utilizando Python e FastAPI.

📌 Sobre o Projeto
Este repositório contém a Etapa 1 do projeto de API de Livros. Nesta fase inicial, a estrutura base da aplicação foi estabelecida, criando o ambiente de desenvolvimento, organizando a arquitetura de pastas e configurando o servidor web para execução da API.

O projeto completo será entregue ao longo de 4 etapas, nas quais a API será expandida até se tornar um sistema completo com persistência de dados, rotas CRUD e validações.

🎯 Objetivos da Etapa 1
[x] Configuração e isolamento do ambiente virtual (.venv).

[x] Estruturação modular de diretórios do projeto (/app).

[x] Definição e instalação das dependências base (FastAPI e Uvicorn).

[x] Criação da instância principal do servidor e verificação da inicialização do serviço.

🛠️ Tecnologias Utilizadas
Linguagem: Python 3.14+

Framework Web: FastAPI

Servidor ASGI: Uvicorn
